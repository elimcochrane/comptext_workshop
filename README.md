# Computational Text Analysis Workshop

This repository contains the materials for the Computational Text Analysis Workshop presented to the University of Kansas's Department of Linguistics.

## Files:

1. .pdf: The slideshow for the first half of the workshop event.
2. .ipynb: The interactive Jupyter notebook for the second half of the workshop event. Run this in Google Colabs, VSCode, or JupyterLab. The file is entirely self-contained; no external downloads or dependencies are required.
